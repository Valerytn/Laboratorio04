Algoritmo secuencial: Preparar té

  1. Hervir agua
  2. Poner la bolsa de té en una taza
  3. Verter el agua caliente
  4. Esperar 3 minutos
  5. Disfrutar

Algoritmo con condiciones y repeticiones: Adivinar un numero

  1. Pensar en un numero secreto
  2. Mientras el usuario no adivine:
    1. El usuario ingresa un numero
    2. Si el número es mayor → decir "mas bajo"
    3. Si el número es menor → decir "mas alto"
    4. Si el número es igual → decir "¡Adivinaste!"
